# PDF отчёты страницы /marketing/

Все PDF собираются из самой страницы сайта, поэтому после любой правки на сайте их можно пересобрать, и они совпадут с сайтом.

```
# из корня репозитория; сайт должен отдаваться с поддержкой Range (подойдёт любой статический сервер)
node marketing/_pdf/build.js http://localhost:8766            # все PDF
node marketing/_pdf/build.js http://localhost:8766 cv-kadirov # только один
```

Нужны Node + Playwright (Chromium) и Python с `pikepdf` и `Pillow`.

| Файл | Что внутри |
|---|---|
| `makro-marketing-2026.pdf` | Полный отчёт для руководства, тёмная версия для показа |
| `makro-marketing-2026-print.pdf` | Тот же отчёт для печати: белый фон, мало краски |
| `team / dash / income / done / issues.pdf` | Отдельные разделы |
| `cv-*.pdf` | Зоны ответственности и резюме сотрудника |

- `report.css` — листы A4, обе темы, дашборд.
- `report.js` — раскладка блоков сайта по листам, дашборд на SVG, перевод в светлую тему для печати.
- `compress.py` — пережимает фото внутри PDF.
